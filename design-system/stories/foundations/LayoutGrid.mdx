# Layout grid

Layout grids give every screen the same structure. Each breakpoint below matches a grid style in Figma (`Grid/Mobile 375`, `Grid/Tablet 768` and so on).

<GridTable />

## Page grid

Add `.layout-grid` to a full-width page container. It switches from 4 to 8 to 12 columns as the screen widens. Resize the window to watch it change.

<LayoutGridDemo />

```html
<main class="layout-grid">
  <section class="col-span-8">Main content</section>
  <aside class="col-span-4">Side panel</aside>
</main>
```

## Baseline

`--grid-baseline` is 4px. Spacing and line heights are all multiples of 4, so text and boxes line up on the same rhythm.
