# Typography

Inter only. One scale covers product and marketing, and a separate set covers article text in the editor. Every text style in Figma is linked to the Typography variables, and every class here is built from the same variables, so a size changes in one place.

## Use it in code

Put a text-style class on the element. Set the colour separately with a `--text-*` token.

```html
<h2 class="display-xs-semibold" style="color: var(--text-primary)">Brand Monitor</h2>
<p class="text-sm-regular" style="color: var(--text-secondary)">Last updated 2 hours ago</p>
```

Need a one-off? Use the variables, never a typed number:

```css
.score-label {
  font: var(--font-weight-medium) var(--font-size-text-xs) / var(--font-line-height-text-xs) var(--font-family-sans);
}
```

Sizes and line heights ship in `rem` (16px base), so text follows the reader's browser font setting. The pixel values are noted beside each one.

## Rules from the team

- Buttons and CTAs are always **Medium**.
- Dropdown and menu items are always **Regular**.
- Nothing in the UI is smaller than **12px**.
- **Regular** for anything people read: body, inputs, menu items, table cells.
- **Medium** for things people act on: buttons, labels, nav items, badges.
- **Semibold** for titles and headers. One Semibold title per card or section.
- **Bold** is rare. Only for editor H1 and marketing emphasis.
