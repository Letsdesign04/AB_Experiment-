These are the raw palette values from the Figma **Primitives** collection. They exist to feed the semantic tokens.

**Don't use these in components.** Use a [semantic token](?path=/docs/foundations-colours-semantic-tokens--docs) instead. If no semantic token fits, add one in Figma first.
