# Gradients

Figma has no gradient styles yet, so these five come from the gradient fills actually used across the file. Each one is named by its job.

<GradientSwatches />

## Use it in code

```css
.loader-bar { background: var(--gradient-brand); }
.plan-badge { background: var(--gradient-premium); color: var(--text-on-brand); }
.plan-badge:hover { background: var(--gradient-premium-hover); }
.hero { background: var(--gradient-dark-hero); color: var(--text-on-dark); }
```

For gradient text, like the VIP stat values, use the helper class:

```html
<span class="numeric-stat gradient-text">500+</span>
```

## Contrast

Gradient text (`.gradient-text`) needs a solid fallback colour for forced-colours mode.

## Off-palette colours

Three stop colours aren't in the colour palette: `#1F4CBE` (brand and premium start), `#1641AE` (premium hover start) and `#022177` (dark hero end). They ship as raw hex for now. Either add them to the Primitives collection in Figma or switch the gradients to the nearest blue (`blue-600`, `blue-700`, `blue-900`).
