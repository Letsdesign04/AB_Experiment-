# Spacing and sizes

A 4pt spacing scale, fixed control sizes and border widths. All of them are variables in the Figma *Spacing* collection. Never type a raw number into padding, margin or gap.

```css
.card {
  padding: var(--spacing-xl);
  gap: var(--spacing-md);
  border: var(--border-width-default) solid var(--border-default);
}
```

## Spacing scale

Steps 2 to 96 are for components and screens. Steps 128 to 256 are for big page sections and marketing.

## Click targets

`--size-target-min` (24px) is the WCAG 2.5.8 minimum click area. A control smaller than 24×24 needs 24px of free space around it. `--size-target-touch` (44px) is for mobile.

## Containers

The max width of page content. Put the content in a container, centre it, and let the page background fill the rest. Bars are shown at 1/6 scale.

<SizeTable kind="container" />

```css

```

## Breakpoints

The screen widths we design for. Each one has a layout grid; see [Layout grid](?path=/docs/foundations-layout-grid--docs). CSS can't use variables inside `@media`, so type the number there and keep it in sync with these tokens.
