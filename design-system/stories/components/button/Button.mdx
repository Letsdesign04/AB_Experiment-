# Button

The one button component for Scalenut, built from the Figma component set **Button** (`↳ Buttons`): 7 hierarchies, 4 sizes and 6 states. Every colour, size and effect is a design token, so a change in Figma flows through to here.

## Use it in code

Load `scalenut.css` (it includes the button), then write a plain `<button>`:

```html
<button type="button" class="btn btn--primary btn--md">
  <svg class="btn__icon btn__icon--leading" aria-hidden="true"><!-- dist/icons/magic.svg --></svg>
  <span class="btn__label">Generate article</span>
</button>
```

## Icons

Leading icon for what the action does, trailing icon for where it goes: `arrow-right` (next step), `arrow-right-up` (opens elsewhere), `return`, `down` (opens a menu). For an icon on its own, use *Icon button*, never a Button with an empty label.

## Pairs

Secondary on the left, Primary on the right, 12px apart (`--spacing-lg`).

## Loading

Set `aria-busy="true"`. The spinner takes the place of the leading icon, the label stays (or says "Saving…"), the button stops responding to clicks, and the width doesn't jump. If it takes more than 10 seconds, show progress text somewhere else. Pair it with a polite live region, for example "Generating article…".

<Canvas of={ButtonStories.Loading} />

If the button has no leading icon, the spinner adds 20px (plus the gap) to its width. Give it a `min-width` if the jump matters.

## Disabled

It's usually better to keep the button on and show an error next to the field. If you do disable it, use `aria-disabled="true"` (not the `disabled` attribute) so it stays focusable, and say why next to it. Your click handler must ignore clicks while `aria-disabled="true"`.

## Keyboard and screen readers

- Tab and Shift+Tab reach every button. Enter and Space press it.
- The focus ring only shows for keyboard focus (`:focus-visible`), not on mouse click. It's red on destructive buttons.
- Icons inside get `aria-hidden="true"`.
- Disabled = `aria-disabled="true"`, so the reason can still be read.
- Loading = `aria-busy="true"` plus a polite live region.

## Accessibility check (WCAG 2.2 AA, from Figma)

- **1.4.3 Label contrast** passes in every active state: white on blue-600 7.3:1, blue-600 on white 7.3:1, red-600 on red-50 4.81:1.
- **1.4.11 Non-text contrast**: Secondary is told apart by its blue label (7.3:1).
- **2.4.7 / 2.4.13 Focus**: 2px white gap + 2px blue-600 ring.
- **2.5.8 Target size**: the smallest button is 32px high, including Link.
- **1.4.1 Use of colour**: Link hover and pressed add an underline, not just a colour change.
- Disabled text (1.88:1) doesn't have to pass 1.4.3, but it always comes with a reason.
