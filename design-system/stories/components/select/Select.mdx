## Usage guidelines

- Use Select for 3–10 mutually exclusive options. Fewer than 3 → Radio buttons. More than 10 → consider a searchable combobox.
- Always include a visible label; never use placeholder text as the only label.
- Group related options with `<optgroup>` for long lists.
