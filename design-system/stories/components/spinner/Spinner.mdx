## Usage guidelines

- **Spinner** — use for single actions (save, upload) or when layout is unknown.
- **Skeleton** — use for page or section loads where the structure is predictable.
- Always include a visually-hidden `aria-label` for screen readers.
- Avoid showing a spinner for operations faster than 300 ms — debounce the display.
